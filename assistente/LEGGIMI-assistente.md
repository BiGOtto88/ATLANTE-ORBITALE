# Keplario - Setup Risolutori Aerospaziali

L'archivio contiene l'infrastruttura aggiornata per i calcolatori richiesti. 

- `index.html`: Strutturata in un layout modulare SPA (Single Page Application, attualmente in blocchi scorrevoli per semplicità) divisa nelle 6 categorie. La libreria Math.js è già integrata via CDN per consentire calcoli complessi (matrici, trigonometria).
- `risolutori.js`: Contiene il primo motore logico a deduzione ("risolutore a input libero") per le manovre orbitali.

Ora ti basta scompattare questa cartella, aprire `index.html` e verificare come il risolutore delle orbite deduca le variabili mancanti in modo automatico.
